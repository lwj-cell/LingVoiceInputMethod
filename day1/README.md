# 凌声输入法 - 基础输入版

凌声输入法是一个 Java 桌面端语音输入法原型。当前版本先完成输入法最基础的闭环：接收语音识别后的文本，进行标点命令转换、简单降噪和编辑命令处理，再写入可编辑文本区。

实际接入麦克风识别时，只需要把 ASR 引擎返回的文本传入输入框，后续处理流程不需要改动。

## 功能说明

- 语音识别文本输入：在输入框中粘贴或输入识别结果。
- 标点转换：支持逗号、句号、问号、感叹号、冒号、分号、括号等口令。
- 编辑命令：支持换行、删除、撤销、清空和复制全文。
- 口语清理：过滤部分常见停顿词，如“嗯”“啊”“那个”。
- 输入统计：展示输入次数、累计字符数和平均处理延迟。

## 运行环境

- JDK 17 或以上
- Windows PowerShell
- 无第三方依赖，全部功能使用 JDK 标准库实现

## 编译运行

```powershell
.\run.ps1
```

也可以手动执行：

```powershell
javac -encoding UTF-8 -d out src\com\lingvoice\day1\LingVoiceDay1.java
java -cp out com.lingvoice.day1.LingVoiceDay1
```

## 设计说明

界面使用 Java Swing 实现，核心处理逻辑集中在 `VoiceTextProcessor` 中。程序没有直接绑定某个语音识别平台，主要负责语音输入法后处理层：把识别文本转换成更适合写作、记录和复制的正式文本。

该版本在准确度、易用性、响应速度和成本之间的取舍如下：

- 准确度：通过固定标点词典和少量停顿词过滤减少常见错误。
- 易用性：窗口中保留输入框、编辑区和常用操作按钮。
- 响应速度：文本处理全部在本地完成，延迟通常为毫秒级。
- 成本：不调用云服务，也不引入外部库，运行成本较低。
