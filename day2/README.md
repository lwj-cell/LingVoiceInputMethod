# 凌声输入法 - 词库增强版

这一版在基础输入能力上加入用户词库、候选建议、历史记录和文本导出。语音输入中经常出现专有名词、英文缩写、人名或项目名识别不准的问题，词库增强版的重点就是让用户可以自己修正这些高频误识别内容。

## 功能说明

- 用户词库：支持添加“识别词 -> 输出词”的替换规则。
- 候选建议：根据当前输入和词库内容给出可选文本。
- 历史记录：保留最近 30 条输入结果，方便回看和复用。
- 文本导出：将编辑区内容保存为 UTF-8 文本文件。
- 基础编辑：保留标点命令、删除、清空、复制等操作。
- 指标统计：展示输入次数、字符数、平均延迟、词库数量和历史数量。

## 运行环境

- JDK 17 或以上
- Windows PowerShell
- 无第三方依赖，全部功能使用 JDK 标准库实现

## 编译运行

```powershell
.\run.ps1
```

也可以手动执行：

```powershell
javac -encoding UTF-8 -d out src\com\lingvoice\day2\LingVoiceDay2.java
java -cp out com.lingvoice.day2.LingVoiceDay2
```

## 使用示例

| 场景 | 输入或操作 | 结果 |
| --- | --- | --- |
| 标点转换 | 项目进入词库增强版逗号加入用户词库句号 | 项目进入词库增强版，加入用户词库。 |
| 词库替换 | 添加 `林沃斯 -> LingVoice` 后输入“林沃斯输入法” | 输出 `LingVoice输入法` |
| 候选建议 | 输入包含词库词条的文本 | 右侧候选列表出现替换结果 |
| 文本导出 | 点击“导出” | 保存为 UTF-8 文本文件 |

## 模块说明

- `LingVoiceDay2`：负责界面布局和事件处理。
- `TextProcessor`：负责标点命令、停顿词清理和词库替换。
- `UserDictionary`：维护用户自定义词条。
- `HistoryBuffer`：保存最近输入历史。
- `MetricTracker`：统计输入效率指标。

## 设计取舍

- 准确度：用户词库补充通用识别结果对专有词汇的不足。
- 易用性：词条可以直接在界面中添加，不需要修改代码。
- 响应速度：词库使用内存结构保存，匹配开销较小。
- 成本：仍然只使用本地处理逻辑，不依赖云端服务。
