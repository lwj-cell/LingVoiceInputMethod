# 凌声输入法 - 综合体验版

凌声输入法是一个 Java 桌面端语音输入法原型，核心目标是提高长文本输入效率。程序把语音识别结果作为输入，完成文本清理、标点转换、词库纠错、编辑命令识别、自动标点和会话统计。

项目没有绑定固定的语音识别厂商。真实使用时，可以将 Vosk、Whisper 或云端 ASR 的识别结果接入输入框，再由本程序完成输入法后处理。

## 功能说明

- 语音文本后处理：支持标点、换行、空格和专业词替换。
- 智能命令：支持撤销、清空、复制全文、删除前 N 个字。
- 降噪处理：过滤“嗯、啊、这个、那个”等口语停顿词。
- 自动标点：根据句式自动补全句号或问号。
- 场景模板：内置会议纪要、客服记录、学习笔记三类模板。
- 用户词库：支持添加自定义识别词和输出词。
- 会话分析：统计输入次数、字符数、平均延迟、命令次数和节省时间估算。
- 显示模式：支持浅色和深色编辑区切换。

## 运行环境

- JDK 17 或以上
- Windows PowerShell
- 无第三方依赖，全部功能使用 JDK 标准库实现

## 模块说明

- `InputEngine`：处理降噪、标点、词库替换、场景格式化和自动标点。
- `CommandEngine`：识别撤销、清空、复制、换行、删除前 N 个字等命令。
- `NoiseFilter`：维护口语停顿词过滤规则。
- `SmartPunctuation`：根据问句特征和句末标点补全文本。
- `UserDictionary`：维护用户自定义词条。
- `SessionMetrics`：统计输入效率、延迟、命令次数和节省时间。

## 设计取舍

- 准确度：用户词库处理专有词汇，自动标点减少后期修改。
- 易用性：常用命令和模板集中在界面中，不需要记复杂快捷键。
- 响应速度：核心逻辑在本地运行，不等待网络请求。
- 成本：不调用收费接口，也不引入第三方运行库。

## 依赖与来源说明

本项目代码使用 Java 标准库和 Swing 编写，不包含第三方依赖。核心输入处理、词库替换、命令识别、统计分析和界面交互逻辑均在源码中实现。
