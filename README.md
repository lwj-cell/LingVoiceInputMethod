# 凌声输入法 LingVoiceInputMethod

凌声输入法是一个 Java 桌面端语音输入法原型，主要解决语音识别结果进入文本编辑区之前的后处理问题。程序不绑定具体语音识别厂商，可以接收任意 ASR 引擎输出的文本，再完成标点转换、口语清理、编辑命令、词库纠错、场景模板和会话统计等处理。

项目关注四个方面：

- 准确度：通过用户词库和标点规则减少专有名词、英文缩写和标点输入错误。
- 易用性：提供桌面窗口、常用按钮、模板和候选建议，降低操作成本。
- 响应速度：核心逻辑在本地运行，文本处理通常为毫秒级。
- 运行成本：只使用 JDK 标准库和 Swing，不依赖收费接口或第三方运行库。

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 标点命令 | 将“逗号、句号、问号、感叹号”等口令转换为中文标点 |
| 编辑命令 | 支持换行、删除、撤销、清空、复制全文、删除前 N 个字 |
| 口语清理 | 过滤“嗯、啊、这个、那个”等常见停顿词 |
| 用户词库 | 支持把容易误识别的词替换成正式写法 |
| 候选建议 | 根据输入文本和词库内容给出候选结果 |
| 历史记录 | 保存最近输入内容，便于查看和复用 |
| 场景模板 | 提供会议纪要、客服记录、学习笔记模板 |
| 会话分析 | 统计输入次数、字符数、平均延迟、命令次数和节省时间估算 |

## 运行环境

- JDK 17 或以上
- Windows PowerShell
- 无第三方依赖，编译运行只需要 JDK

## 运行方式

以综合体验版为例：

```powershell
cd day3
.\run.ps1
```

也可以进入其他版本目录运行：

```powershell
cd day1
.\run.ps1
```

脚本会自动创建 `out` 编译目录，执行 `javac` 编译并启动对应版本的窗口程序。

## 设计说明

项目采用轻量分层思路：

- 界面层：使用 Java Swing 实现输入框、编辑区、词库面板、模板按钮和统计区域。
- 输入处理层：负责标点转换、停顿词过滤、词库替换、自动标点和场景格式化。
- 命令处理层：识别撤销、清空、复制、换行、删除前 N 个字等命令。
- 统计层：记录输入次数、命令次数、累计字符数和平均处理延迟。

语音识别模块没有被写死在项目中。这样做的好处是后续可以接入不同来源的识别结果，例如本地识别模型、系统语音输入或云端 ASR，而输入法后处理逻辑仍然可以复用。

## 验证方式

建议检查以下功能：

1. 运行 `day1/run.ps1`，验证标点转换、换行、删除、撤销和复制。
2. 运行 `day2/run.ps1`，添加一条用户词库，验证词库替换、候选建议、历史记录和文本导出。
3. 运行 `day3/run.ps1`，验证删除前 N 个字、自动问号、模板插入、深色模式和会话分析。
